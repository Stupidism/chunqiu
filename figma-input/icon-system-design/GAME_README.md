# 春秋甲骨文风格游戏界面

这是一个基于文明6界面布局的甲骨文风格策略游戏界面，采用中国商周时期的甲骨文和青铜器设计语言。

## 🎨 设计特色

### 配色方案
- **青铜器绿锈**：主色调，象征古代青铜器的庄重与历史厚重感
- **陶器橙**：辅助色，代表温暖与文明的火种
- **玉石青**：点缀色，象征高贵与礼制
- **黄金**：强调色，表现权力与财富
- **朱砂红**：军事与警告
- **紫玉**：文化与艺术
- **竹简丝帛**：背景色，营造古朴氛围
- **墨色**：文字颜色

### 图标系统
包含88个甲骨文风格图标，涵盖9大类别：
1. **文明标识**：秦、齐、楚、晋、吴、越、郑、宋、鲁、燕
2. **军事单位**：战士、弓手、骑兵、投石车、斥候等
3. **建筑**：宫殿、粮仓、兵营、市场、学宫、祭坛等
4. **产出资源**：粮食、生产、金币、科研、文化、信仰
5. **地形**：平原、草原、森林、山脉、河流、湖泊等
6. **战略资源**：铁矿、铜矿、马匹、硝石、丝绸、玉石等
7. **奢侈资源**：茶叶、瓷器、香料、漆器等
8. **操作按钮**：攻击、防御、移动、驻守、治疗、升级等
9. **时代标识**：远古、青铜、铁器、帝国

## 🎮 界面布局

### 顶部信息栏
- 文明标识与回合数
- 资源统计（金币、科技、文化、信仰）
- 功能按钮（科技树、政策、外交、设置）

### 左侧面板
- 城市列表（可选择查看详情）
- 军事单位列表（显示HP和移动力）

### 中央地图区域
- 六边形地图网格系统
- 山海经风格神兽装饰（应龙、凤凰、麒麟）
- 地图交互功能

### 右侧详情面板
- 选中城市的详细信息
- 建筑列表
- 周边地形与资源

### 底部控制栏
- 小地图
- 单位行动按钮（移动、攻击、驻守、建造）
- 回合结束按钮（带旋转装饰动画）

## 🛠️ 技术实现

- **React + TypeScript**：组件化开发
- **Tailwind CSS v4**：现代化样式系统
- **SVG 图标**：矢量图标，保证清晰度
- **CSS 自定义属性**：主题颜色管理
- **甲骨文象形设计**：每个图标都基于真实的甲骨文字形

## 🎯 设计原则

1. **历史准确性**：图标设计参考《甲骨文合集》等权威资料
2. **视觉统一**：线条粗细变化模拟刻刀质感
3. **文化内涵**：融入中国传统文化元素
4. **现代交互**：保持良好的用户体验
5. **古朴典雅**：营造商周时期的历史氛围
