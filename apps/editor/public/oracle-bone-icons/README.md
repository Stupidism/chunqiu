本目录包含春秋项目使用的甲骨文/金文/小篆图标。

## 📁 目录结构

```
oracle-bone-icons/
├── units/          # 单位图标 (战士、弓手、骑兵等)
├── buildings/      # 建筑图标 (宫殿、粮仓、兵营等)
├── yields/         # 产出图标 (粮食、生产、金币等)
├── terrain/        # 地形图标 (山脉、森林、河流等)
├── resources/      # 资源图标 (铁矿、丝绸、玉石等)
├── status/         # 状态/操作图标 (攻击、防御、移动等)
├── eras/           # 时代图标 (远古、青铜、铁器等)
└── ui/             # UI 通用图标 (设置、确认、取消等)
```

## 🌐 数据来源

1. **oraclebone.org** - 主要来源，提供甲骨文 JPG 图片
2. **汉典 (zdic.net)** - 补充来源，提供甲骨文/金文/小篆 SVG 矢量图

## 📝 字形说明

部分字符使用了替代字形：

| 原字 | 替代字 | 字形类型 | 说明 |
|------|--------|----------|------|
| 草 | 艸 | 甲骨文 | 艸是草的本字 |
| 泽 | 澤 | 小篆 | 繁体字 |
| 泥 | 土 | 甲骨文 | 以土代泥 |
| 铁 | 鐵 | 小篆 | 繁体字 |
| 茶 | 荼 | 小篆 | 荼是茶的古字 |
| 瓦 | 陶 | 金文 | 以陶代瓦 |
| 击 | 擊 | 小篆 | 繁体字 |
| 医 | 醫 | 小篆 | 繁体字 |

部分字符使用金文（bronze script）代替甲骨文，因为这些字在甲骨文时代尚未出现。

## 🔧 下载脚本

项目包含三个下载脚本：

```bash
# 1. 从 oraclebone.org 下载主要图标
node scripts/download-oracle-bone-icons.mjs

# 2. 从汉典下载缺失的图标
node scripts/download-zdic-icons.mjs

# 3. 下载替代字符
node scripts/download-alternatives.mjs
```

## 🎨 使用建议

这些图标可以作为 Figma 设计的参考素材：

1. **JPG 图片** (100x100px) - 适合作为参考，需要在 Figma 中描摹为矢量图
2. **SVG 矢量图** - 可直接导入 Figma 使用，建议统一调整样式

建议在 Figma 中：
- 统一线条粗细和圆角
- 统一图标尺寸 (推荐 24x24 或 32x32)
- 应用项目设计系统的颜色变量
