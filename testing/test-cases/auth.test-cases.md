## 测试用例列表

### TC-AUTH-001: 用户注册 - 正常流程

| 项目 | 内容 |
|------|------|
| 用例ID | TC-AUTH-001 |
| 用例名称 | 用户注册 - 正常流程 |
| 优先级 | P0 |
| 前置条件 | 用户未登录，数据库可访问 |

**测试步骤：**
1. 访问注册页面 `/register`
2. 输入有效用户名（4-20位字母数字）
3. 输入有效密码（8-32位，包含大小写字母和数字）
4. 确认密码与密码一致
5. 点击注册按钮

**预期结果：**
- 注册成功提示
- 自动跳转到登录页面
- 数据库中创建新用户记录
- 密码以哈希形式存储
