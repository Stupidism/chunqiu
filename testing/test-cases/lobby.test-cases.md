## 测试用例列表

### TC-LOBBY-001: 查看房间列表

| 项目 | 内容 |
|------|------|
| 用例ID | TC-LOBBY-001 |
| 用例名称 | 查看房间列表 |
| 优先级 | P0 |
| 前置条件 | 用户已登录 |

**测试步骤：**
1. 登录后进入游戏大厅
2. 查看房间列表区域

**预期结果：**
- 显示当前所有可加入的房间
- 房间信息包含：房间名、房主、当前人数、游戏模式、状态
- 列表自动刷新或支持手动刷新
